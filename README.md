A premium, production-ready motorcycle landing page built with **Next.js 16**, **TypeScript**, **Tailwind CSS v4**, **Framer Motion**, and **Lucide React**.

## 📞 Contact
**Phone:** 0932912020

## 🚀 Tech Stack
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React Icons
- Mobile-First Responsive Design
- SEO Optimized

## 📄 Sections
1. **Hero** — Full-screen background, logo, CTA button
2. **Motorcycle Models** — 10 images with lightbox
3. **Gallery** — 11 gallery images with swipe/pinch support
4. **Business License** — License card with zoom
5. **Why Choose Us** — Feature cards
6. **Call to Action** — Phone CTA section
7. **Footer** — Business info

## 🏗️ Getting Started
```bash
npm install
npm run dev
```

## 🌐 Deployment
Deployed on Vercel. Visit: [Live Site](https://motorcycle-landing-page-five.vercel.app)

## 📁 Image Folders
Place your actual images in:
- `public/hero/hero.jpg` — Hero background
- `public/logo.png` — Business logo
- `public/motorcycles/bike1.jpg` → `bike10.jpg`
- `public/gallery/gallery1.jpg` → `gallery11.jpg`
- `public/license/license.jpg`
